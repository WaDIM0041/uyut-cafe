# УЮТ — домашнее кафе с комплексными обедами

Одностраничный лендинг с эффектами: затемнённый hero-слайдер «интерьер/фасад» с плавным появлением из глубины, меню с данными из `js/menu.js`, модальное окно бронирования с валидацией и сохранением в `localStorage`, таймер спецпредложения, чат-бот Telegram и ссылка VK.

## Быстрый старт

```bash
# Локальный запуск
python3 -m http.server 8000
# или
npx serve .
```

## Деплой на GitHub Pages

Репозиторий уже содержит workflow `.github/workflows/pages.yml` — при пуше в `master`/`main` сайт автоматически задеплоится на GitHub Pages. Нужно только:

1. В настройках репозитория (Settings → Pages) для источника указать **GitHub Actions**.
2. Запушить код (или вызвать workflow вручную вкладкой Actions).

## Как поменять контакты и ссылки

Все ссылки, телефон и адрес — в одном месте, в начале файла `js/main.js`:

```js
const CONFIG = {
  telegram: "https://t.me/uyut_cafe",   // чат-бот Telegram
  vk: "https://vk.com/uyut_cafe",       // сообщество VK
  phone: "+7 (999) 123-45-67",
  phoneHref: "+79991234567",
  address: "Ультрамариновая улица, 4, Санкт-Петербург",
  hours: "Пн–Вс · 09:00–22:00",
  deadlineDays: 1                        // дедлайн спецпредложения, дни
};
```

## Как добавить свои фото (внешний вид/интерьер и блюда)

Сайт сам подхватит реальные фотографии, если положить файлы в папку `images/` — подложки-заглушки будут заменены автоматически. Ничего переименовывать не нужно:

| Куда положить файл | Что покажется |
|---|---|
| `images/hero-interior.jpg` | Интерьер кафе (первый слайд hero) |
| `images/hero-exterior.jpg` | Фасад кафе снаружи (второй слайд hero) |
| `images/cafe-interior.jpg` | Фото внутри в блоке «Гости о нас» |
| `images/dishes/<slug>.jpg` | Фото блюда, где `<slug>` — поле `img` в `js/menu.js` |

У каждого блюда уже есть цветная SVG-иллюстрация (`images/dishes/<slug>.svg`) — она показывается, пока нет реального фото. Как только положите `.jpg` с тем же именем, иллюстрация автоматически заменится на фотографию.

Рекомендация: горизонтальные фото 1600×900+ для hero, для блюд — 800×600.

## Как изменить меню

Откройте `js/menu.js`. Категории — ключи объекта, блюда — элементы массива:

```js
{ img: "kotlet", icon: "🍖", name: "Котлета по-домашнему", desc: "…", price: 380, badge: "Хит", tag: "320 г" }
```

Поле `icon` — эмодзи для цветной SVG-иллюстрации блюда (используется, пока нет реального фото). Поле `img` — имя файла `images/dishes/<slug>.svg` и будущего `<slug>.jpg`.

## Как добавить карту

В `index.html` найдите блок `.map-fallback` в секции `#contacts` и замените его на iframe Яндекс.Карт/Google Maps (адрес уже есть в `CONFIG`).

## Бронирование

Кнопка открывает модальное окно в предпросмотре. Валидация: имя, телефон (маска +7), дата (не в прошлом), время. Записи сохраняются в `localStorage` (ключ `uyut_bookings`) и показываются в модалке. После успешной брони — toast и авто-закрытие через 2,2 с.

# Материалы для A/B-тестирования и дизайна

## 3 варианта заголовка H1

1. **«Обед, после которого хочется остаться ещё на чай»** (сейчас в коде — акцент на чувствах и «домашности»)
2. «15 минут до обеда, который пахнет детством» — акцент на скорости и ностальгии
3. «Комплексный обед за 430 ₽, и вам не стыдно позвать коллег» — акцент на цене и соц. статусе

Замена: в `index.html` найдите `<h1 class="hero__title">`.

## Идеи визуального сопровождения по блокам

- **Hero**: крупное тёплое фото интерьера со свечами на деревянном столе; фото фасада в сумерках с горящими окнами. На переднем плане — «плавающая» стеклянная карточка с описанием.
- **Бегущая строка**: движущиеся названия блюд шрифтом с засечками — эффект «меню на вывеске».
- **Проблема**: фото человека с бутербродом у монитора (контраст к тёплому интерьеру), крупный план «еды на бегу».
- **Решение**: 4 карточки с тёплыми иконками (тарелка с паром, часы, кресло, семья); «билет» с ценой комплекса.
- **Как работает**: 3 шага с нумерацией «01/02/03» и стрелками.
- **Меню**: карточки блюд с аппетитными фото, бейджи «Хит/Новинка», фильтр-табы по категориям.
- **Соцдоказательства**: анимированные счётчики (2400 обедов, 15 мин), 3 карусель-отзыва с аватарами и звёздами.
- **FAQ**: аккордеон с иконкой «+→✕».
- **Оффер**: «билет» с градиентной рамкой, живой таймер обратного отсчёта, плашка «Осталось 7 мест».
- **Контакты**: карточки с иконками + встроенная карта с сепия-фильтром, крупные кнопки Telegram/VK.

## Рекомендации по навигации

Одностраничник уже содержит якорное меню: О кафе · Зачем · Меню · Отзывы · Вопросы · Контакты + CTA «Забронировать». При переходе на многостраничную структуру:

- `/` — лендинг (текущий).
- `/menu` — полное меню с ценами и составом (источник — `js/menu.js`).
- `/booking` — отдельная страница бронирования с календарём и историей броней.
- `/gallery` — фотогалерея «внутри/снаружи».
- `/reviews` — отзывы с формой добавления.

Переиспользуйте `js/menu.js`, `CONFIG` из `js/main.js` и стили — блоки уже модульные.
